NEW ROOM

Create Your Room Reference Library

Upload a room model and reference photos with camera information. Once preparation is complete, you can localize new photos.

Supports raw Polycam data ZIPs, 7-Scenes, or a ZIP containing photos and references.json. A textured GLB exported by MultiSet can be used directly as the 3D model; combine it with your own posed or synthetic reference images to build a local localization library. The data must include camera intrinsics, capture poses, and the model-coordinate relationship. Download a general-format example ↗

Data Format and Advanced Options
Sampling and coordinate options apply only to raw 7-Scenes data; prepared reference packages retain their internal settings. Polycam data and the GLB must be exported from the same scan.

Building the library usually takes from several seconds to a few minutes, depending on the number of photos and computer performance. If it fails, you can keep the uploaded files and try again.
