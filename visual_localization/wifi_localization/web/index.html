建立你的房间参考库

上传房间模型与带相机信息的参考照片，准备完成后即可用新照片定位。

支持 Polycam 原始数据 ZIP、7-Scenes，或照片与 references.json 的 ZIP。MultiSet 导出的 textured GLB 可以直接作为三维模型；再配合你们自己的 posed/synthetic reference images 建立本地定位库。需包含相机内参、拍摄位姿及模型坐标关系。下载通用格式示例 ↗

数据格式与高级选项
抽样和坐标选项只用于原始 7-Scenes；已准备好的参考包沿用包内设置。Polycam 数据和 GLB 请使用同次扫描的导出。

建库通常需几十秒到数分钟，取决于照片数量和电脑性能。失败后可保留上传文件重试。
